## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn
- Git (optional)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/josaa98.git

# Navigate to project directory
cd josaa98

# Install dependencies
npm install
```

### Development Server

```bash
# Run development server
npm run dev

# Open [http://localhost:5173](http://localhost:5173) in your browser
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🎨 Customization

### Update Contact Information

Edit the phone and WhatsApp numbers at the top of `src/App.jsx`:

```javascript
const PHONE = '0249778376'
const WHATSAPP = '233249778376'
```

### Add or Replace Photos

Place your photos in `public/images/` and update the filenames in `src/App.jsx`:

- **Hero section**: `hero.png`
- **Residential Construction**: `residential.png`
- **Commercial Construction**: `commercial.jpeg`
- **Civil Works**: `civil.jpeg`
- **Renovation**: `renovation.jpeg`
- **Project Management**: `planning.jpeg`

> **Note**: The site automatically shows blueprint-style placeholders if images are missing.

### Modify Services

Edit the `SERVICES` array in `src/App.jsx` to add, remove, or modify service offerings:

```javascript
const SERVICES = [
  { icon: Home, title: 'Residential Construction', tag: 'Design | Build | Finish', img: 'residential.png' },
  // Add more services here...
]
```

### Update Company Values

Edit the `VALUES` array in `src/App.jsx`:

```javascript
const VALUES = [
  { icon: ShieldCheck, title: 'Quality Workmanship', text: 'Solid construction built with care...' },
  // Modify values here...
]
```
